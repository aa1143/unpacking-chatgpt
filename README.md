# 拆开 ChatGPT

用后端工程师的视角，把 ChatGPT 从模型原理到工程应用讲明白。

这个项目用于管理《拆开 ChatGPT》系列的公众号文章、视频脚本、白板分镜、封面、社交平台文案、参考资料和发布记录。

## 系列定位

不是工具操作教程，也不是从公式开始的大学课程，而是：

> 以 ChatGPT 为大众入口，用具体问题拆解大语言模型如何工作、如何训练、为什么出错，以及如何成为完整的 AI 系统。

内容叙事遵循：

```text
有趣的问题
→ 生活或产品现象
→ 底层机制
→ 工程类比
→ 实际影响
→ 下一期悬念
```

## 内容结构

- 第一阶段：ChatGPT 怎么回答问题——Token、Embedding、位置、Attention、Transformer、生成。
- 第二阶段：ChatGPT 怎么获得能力——预训练、损失函数、反向传播、指令微调、RLHF、DPO。
- 第三阶段：ChatGPT 如何成为产品——幻觉、上下文、RAG、工具调用、Agent、AI 编程。

完整规划见 [ROADMAP.md](ROADMAP.md)。

## 视觉系统

- 公众号封面：黑白雕刻、冷白高对比、单一思想隐喻、少量暗红强调。
- 竖屏视频：1080×1920；上方标题，中间1080×810的4:3白板，下方字幕和平台安全区。
- 总览、架构、流程：提前画好的 Excalidraw 白板。
- 单点概念、推导、例子：iPad 逐步手绘。

封面统一使用 `$engraved-knowledge-cover` Skill。最终中文标题应独立排版，不让图片模型直接生成。

## 制作流程

```text
选题与研究
→ 公众号文章
→ 压缩为口播稿
→ 设计白板和分镜
→ 录制与剪辑
→ 发布公众号、抖音、小红书、X
→ 记录链接和数据
→ 根据反馈迭代下一期
```
