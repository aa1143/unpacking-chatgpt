# 第一期白板规划

## 画布

- 白板比例：4:3。
- 嵌入竖屏后的白区：1080×810。
- 安全边距：左右60–80px，上下40–60px。
- 外部紫色标题区已经放完整视频标题，白板内部不重复完整标题。

## 白板信息结构

```text
┌────────────────────────────────────────────┐
│  一句回答的诞生                             │
│                                            │
│        猫最喜欢吃的食物是……                 │
│                       ↓                    │
│                                            │
│   ①切成Token    ②变成向量    ③处理上下文    │
│  [猫][最喜欢] → [数字向量] → [Transformer]  │
│                                     ↓      │
│                              ④预测下个Token │
│                              鱼    ███████  │
│                              肉    ████     │
│                              猫粮  ███      │
│                                     ↓      │
│  ⑤放回上下文                                │
│  ……食物是 → 鱼 → 类 → ……                   │
│             └────再次预测────→ ↑            │
└────────────────────────────────────────────┘
```

## 配色

- 正文和线条：深灰黑 `#29252F`
- 主要结构：深紫 `#51358A`
- 当前重点：橙黄 `#FFB547`
- 辅助背景：浅紫 `#F1ECFA`
- 红色只表示错误或否定，本期基本不用。

## 关键设计

1. 左上角只放小标签“一句回答的诞生”。
2. 顶部中央放浅紫圆角输入框：“猫最喜欢吃的食物是……”。
3. 中间横向放Token、向量、Transformer、概率四个节点。
4. 底部重点画“生成 → 放回上下文 → 再次预测”的回环箭头。
5. 概率条标注“示意”，不写具体百分比。

## 呈现方式

- 第一期是总览篇，使用提前画好的Excalidraw画布。
- 开头展示完整地图约1秒，随后放大案例。
- 每讲一个节点就移动到对应区域，并降低其他节点透明度。
- 结尾缩回全景图，形成完整认知闭环。
- 后续Token、Embedding、Attention等细节篇可更多使用iPad边画边讲。
