# 第一期视频分镜

建议时长：2–3分钟。

| 时间 | 画面 | 口播作用 |
|---|---|---|
| 0–2秒 | 完整白板图快速出现 | 建立专业感和内容预期 |
| 2–6秒 | 放大“猫最喜欢吃的食物是……” | 抛出案例与悬念 |
| 6–15秒 | “鱼？”出现后被圈起 | 认知反转：不是先想好答案 |
| 15–35秒 | Token卡片依次突出 | 解释文字先被切成片段 |
| 35–55秒 | 数字编号变成小型向量矩阵 | 区分编号和向量表示 |
| 55–90秒 | Transformer叠层结构 | 说明模型结合上下文计算 |
| 90–115秒 | 鱼、肉、猫粮概率条 | 说明只预测下一个Token |
| 115–145秒 | 鱼→类→……并画回环箭头 | 展示循环生成机制 |
| 145–165秒 | 镜头缩回完整流程图 | 总结五个步骤 |
| 165–180秒 | 推近Token节点 | 引出第二期 |

## 剪辑原则

- 前3–6秒必须明确主题。
- 每3–5秒产生一次视觉变化：缩放、移动、圈画、节点变亮或箭头出现。
- 白板里只放关键词、节点和箭头；完整解释由口播和字幕承担。
- 开头或结尾留1–2秒无字幕的干净全景帧，方便直接选作封面。
